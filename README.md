\# QST 鸿蒙智能小车



基于 Hi3861 + STM32 的智能小车项目。



\## Hardware



\- Hi3861 WiFi模块

\- STM32F103C8T6

\- L9110S电机驱动

\- OLED显示

\- SHT20温湿度传感器

\- AP3216C光照/接近传感器

\- 超声波模块

\- 舵机

\- WS2812 LED



\## Directory



\- Hi3861: OpenHarmony侧代码

\- STM32: STM32侧代码

\- docs: 文档资料

\- report: 实验记录

\- tools: 工具说明
